# Weirdest Job Title: Blind Judge Showdown

Entry for the make.fun "Weirdest Job Title" contest. The program writes a
single job title — a plausible corporate title with one absurdly narrow
specialty — to `/output/entry.txt`:

**Senior Specialist, Telling People They're on Mute**

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Requires only Python 3 (standard library only). The output file contains
the title alone, 49 characters, UTF-8 text.
